# Basic reverse shells collection

List of shells:

* `bind shell` - This shell forces the victim server to give a shell to whoever connects out to it

* `pipe shell` - This shell forces the victim server to make a connection to a an attacker address

* `web shells` - Shells that can be used for web servers, php and python

* `exec shells` - Replaces current shell instead of creating new child processes

* `other shells` - Shell that use telnet, awk, busy box and exported environment variables

** To use a reverse shell, ensure that you open the shell and replace the address with your own attacker IP address and port number and set up a listener for the connection **
